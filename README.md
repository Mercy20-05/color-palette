# Color Palette Generator — Web Development Track

A responsive, interactive **Color Palette Generator** web tool developed for the Level 1, Day 14 curriculum requirement. It enables designers and developers to rapidly generate, lock, inspect, and copy hex swatches directly to their clipboard.

## 💡 Technical Approach

### 1. Structure & Layout (`index.html` & `style.css`)
- **Full Viewport Layout**: The application utilizes CSS Flexbox (`flex: 1`) to ensure the swatches distribute equally across the viewport.
- **Responsive Direction**: On mobile devices (`< 768px`), the swatches stack vertically for intuitive scrolling. On tablet/desktop screens, they expand horizontally into adjacent columns.
- **Dynamic Text Contrast (Luminance Calculation)**:
  Instead of hardcoding text colors, the app calculates perceived luminance using the formula:
  $$\text{Luminance} = \frac{0.299 \times R + 0.587 \times G + 0.114 \times B}{255}$$
  - If $\text{Luminance} > 0.55$, the text is switched to dark (`#1a1a1a`).
  - Otherwise, text switches to pure white (`#ffffff`). This ensures high contrast accessibility across all randomly generated background colors.
